# Party audio

Drop your own audio files here (`.mp3`, `.wav`, `.ogg`, `.m4a`, `.flac`) and
party mode will pick one at random instead of the built-in beat.

Nothing in this folder is committed — see `.gitignore`. Use music you have the
rights to.

If the folder is empty, `music.py` synthesizes a 128 BPM loop from scratch
(kick, snare, hats, square bassline, sine arpeggio) so party mode works out of
the box with no files and no downloads.
